# ATS — Ateliê de Toalhas Sagradas

Pacote estático pronto para publicar no GitHub Pages.

## Publicar sem compartilhar credenciais

1. No GitHub, crie um repositório **público** (por exemplo, `ats-toalhas`).
2. Envie o arquivo `index.html` desta pasta para a raiz do repositório.
3. Abra **Settings → Pages** no repositório.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/(root)`, depois clique em **Save**.
6. Após a publicação, o endereço será:

   `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`

Nenhum token de acesso é necessário para esse fluxo pela interface do GitHub.
